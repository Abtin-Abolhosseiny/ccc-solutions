# CCC Solutions — Abtin Abolhosseiny

My solutions to Canadian Computing Competition (CCC) problems, with explanations. The CCC is run by the University of Waterloo's Centre for Education in Mathematics and Computing (CEMC): 5 problems, 3 hours, scored out of 75.

Official problems and past papers: https://cemc.uwaterloo.ca/contests/ccc — problem statements belong to CEMC and are linked, not copied here. All code and explanations in this repo are my own work.

## My result
Canadian Computing Competition participant — 88% (division/year/score details to be added from certificate).

## Structure
```
solutions/
  <year>-<division>-<problem>/
    solution.cpp   (or solution.py)
    README.md      approach, complexity, edge cases
    tests/         sample + edge-case inputs with expected outputs
```

## How to run a solution
```bash
# C++
g++ -std=c++17 -O2 -o solution solution.cpp && ./solution < tests/sample1.in

# Python
python3 solution.py < tests/sample1.in
```
